# Pot gameplay test — 2026-10-30

I ran the 26.3 Fabric client against a local vanilla 26.3 multiplayer server. Pot was enabled with its default setting to restore the previous hotbar slot. Stone was selected in slot 0; each test potion was in another hotbar slot. The module uses the ordinary item interaction at the player's current view direction and switches itself off after one throw. The [ClickGUI frame](2026-10-30-pot-gui.png) shows the Pot row below the healing modules.

| Potion | Trigger | Server result |
| --- | --- | --- |
| Healing splash | Enabled in saved configuration before join | The only potion was consumed; inventory and `SelectedItem` showed stone |
| Poison splash | Enabled through the ImGui ClickGUI | The poison potion was consumed; inventory and `SelectedItem` showed stone |
| Slowness lingering | Enabled through the ImGui ClickGUI | The lingering potion was consumed; inventory and `SelectedItem` showed stone |

After each throw the saved module state was disabled. The splash and lingering tests establish item use and slot restoration; this test did not place a target at the landing point or measure potion-effect application. The local server had no anticheat plugin.
