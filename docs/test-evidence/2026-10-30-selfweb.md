# Self Web gameplay test — 2026-10-30

Tested with Anomoly on a local vanilla Minecraft Java 26.3 server. PlayerC stood in survival at `(60.5,100,50.5)` over a stone floor, with stone selected in hotbar slot 0. Self Web used its default line-of-sight check and three-tick attempt interval. The server console queried blocks, inventory, and selected item.

| Probe | Server observation |
| --- | --- |
| No cobweb | The cell `(60,100,50)` remained air before a cobweb was supplied. |
| Hotbar placement | With four cobwebs in hotbar slot 1, the cell became `minecraft:cobweb`; the stack fell to three and stone remained selected. |
| Offhand repair | After clearing the hotbar stack, giving two cobwebs in the offhand, and removing the placed web, Self Web replaced it. Stone remained selected. |
| Material exhausted | After clearing the offhand and removing the web again, the cell remained air. |

The test verifies ordinary cobweb placement and repair on a flat floor. Movement effects, water, partial blocks, protected regions, and third-party anticheats need separate gameplay tests.
