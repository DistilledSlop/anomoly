# AntiWeb and NoWeb local gameplay test — 2026-10-30

I tested Anomoly against a local vanilla Minecraft Java 26.3 server. A one-block-wide stone path ran from z=80 to z=94 at y=120, with a cobweb at (80, 121, 84). The player started at (80.5, 121, 80.5), faced south, and held forward for about 1.5 seconds. Other movement modules were disabled. The server's `data get entity ... Pos` command supplied the final positions; the built-in profiler sampled client movement every tick.

| Setting | Final server z | Result |
| --- | ---: | --- |
| AntiWeb off | 84.258 | Slowed at the web |
| Air | 87.188 | Passed through the web |
| AntiWeb off, repeated | 84.307 | Slowed again |
| Strafe, strength 0.23 | 85.116 | Moved farther through the web |
| Strafe, same settings repeated | 85.116 | Reproduced the first Strafe result |

The Strafe trace recorded horizontal velocity 0.23 while inside the web. The server sent no position corrections during either Strafe movement run; its corrections were the deliberate test teleports. In a separate control, I replaced the web with powder snow. The AntiWeb-on and off results were similar (z=86.455 and z=86.237), consistent with the cobweb-only check in the client hook.

I also enabled Strafe's vertical override at 0.3 and teleported the player directly into the cobweb. The server observed y rise from 121.0 to 121.915 and then 122.013 while the player remained connected. The only profiler correction was the deliberate teleport into the test block. This test establishes that the option changes vertical motion on a vanilla server; it does not establish compatibility with third-party anticheats.

Air and Strafe are available in AntiWeb's settings. The catalog's NoWeb entry shares these behaviors. Other upstream NoWeb variants, including Grim2365, Intave14, and PlaceWater, and AntiWeb's Timer, Solid, and Fly variants remain unfinished. The [LiquidBounce NoWeb documentation](https://liquidbounce.net/docs/modules/movement/noweb) and [ThunderHack AntiWeb implementation](https://github.com/Pan4ur/ThunderHack-Recode/blob/49c76bcc5a5e4fbd12b06305c09f0c8fb76c510b/src/main/java/thunder/hack/features/modules/movement/AntiWeb.java) informed that scope comparison.
