# Offhand local gameplay test — 2026-10-30

I ran the Fabric 26.3 client with Anomoly on a local vanilla 26.3 multiplayer server. Server commands populated inventory slots and queried `equipment.offhand`, `Inventory`, and `Health` after client ticks. The swaps below were server observed inventory changes, not just client visuals.

| Case | Server observation |
| --- | --- |
| Totem mode | With a shield in the offhand and a totem in inventory slot 0, the offhand became a totem and the shield moved to inventory slot 0. |
| No totems | With a shield in the offhand and two crystals in inventory, Totem mode equipped the crystal stack through its enabled fallback. |
| Automatic idle | At 20 health, with a shield in the offhand and a totem available, Auto mode kept the shield. |
| Low health and recovery | Eight damage lowered health from 20 to 12; Auto mode equipped the totem and moved the shield to inventory. Instant Health restored 20 health; the shield returned to the offhand and the totem returned to inventory. |
| Manual keys | Bound Crystal, Gapple, and Strength controls equipped crystals, an enchanted golden apple over an ordinary golden apple, and a potion whose `potion_contents` was `minecraft:strength`. The Cycle control changed the saved mode from Block to Auto. |
| Building block | Block mode equipped stone from inventory while leaving sand untouched. A displaced shield was stored in the stone's prior slot. |
| Crystal danger | In Auto mode with stone in the offhand, summoning an end crystal roughly three blocks away equipped a totem. Killing the crystal restored the same 16-stone stack to the offhand. |
| Automatic sword context | With Kill Aura enabled, an iron sword selected, a strength potion and golden apple available, and a shield in the offhand, Auto mode equipped the strength potion. Granting the Strength effect changed the offhand to the golden apple. The server still showed the iron sword selected. |
| Module conflict | With Offhand set to Gapple, Auto Totem and Inventory Cleaner enabled, a totem and apple available, and Inventory Cleaner set to prefer a shield, the offhand became and remained a totem. Inventory Cleaner moved the apple into its food hotbar slot but did not replace the offhand. |

The first Auto-mode launch exposed a null handling crash when no context matched. I fixed the guard and repeated the idle and danger cases successfully. These runs did not exercise fall prediction, primed creepers, Crystal Aura or Scaffold contexts, open menus, full inventories, or third-party anticheats.
