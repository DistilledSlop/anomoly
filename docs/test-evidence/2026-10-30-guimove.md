# GUI Move and Inventory Move gameplay test — 2026-10-30

Tested Anomoly on a local vanilla Minecraft Java 26.3 server. Xvfb sent real key presses to the client while its inventory, chest, and chat screens were open. Server commands read position and view rotation. GUI Move was enabled for the positive probes, then disabled with Anomoly's End panic key for the movement control.

| Probe | Server observation |
| --- | --- |
| Inventory movement | At `(50.5, 100, 50.5)`, holding W for two seconds while the inventory screen remained visible moved the player to `(50.5, 100, 59.3465)`. The [inventory screenshot](../screenshots/guimove-inventory.png) was captured after the movement. |
| Inventory jump | With the inventory still open, holding Space raised the server-observed Y coordinate to `101.1768` from ground level `100`. |
| Arrow view rotation | Holding the right arrow for about one second while the inventory was open changed server-observed yaw from `0°` to `76°`. |
| Chat guard | After opening chat, holding W for about one second left position at `(50.5, 100, 50.5)`. |
| Disabled control | After End disabled GUI Move, holding W for two seconds in the open inventory left position unchanged at `(50.5, 100, 50.5)`. |
| Rebound forward key | The Minecraft forward binding was changed from W to I. Holding I for about one second in the open inventory moved Z from `50.5` to `54.8134`; holding W afterward left Z unchanged. |
| Container movement | With a real chest screen open, holding A for about one second moved X from `50.5` to `54.8134`. The [chest screenshot](../screenshots/guimove-chest.png) shows the chest screen still open afterward. |

The final build adds explicit guards for sign, book, and command-block text editors. Those editors, the optional sneak passthrough, the All screen scope, arbitrary keybindings beyond the one rebound forward key, and third-party anticheats still need separate gameplay checks.
